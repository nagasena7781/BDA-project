Project & Presentation Guide

Use this explanation during your college demonstration.

Be transparent: This is a front-end simulation, not a live Hadoop cluster. Explain that the interface models HDFS and MapReduce concepts for demonstration without installing Ubuntu.

Abstract

This project demonstrates distributed file storage and batch data analysis inspired by Apache Hadoop. Users upload text or CSV datasets. The application models file blocks and DataNode placement, then performs a MapReduce-style word count to identify word frequencies. Results are visualized and exported as reports. This browser implementation runs on Windows without requiring Hadoop or Ubuntu.

Architecture

🧑‍💻ClientUpload files
📋NameNodeMetadata
💽DataNodesBlock storage
⚙️MapReduceAnalyze data
1. Client:

Selects datasets and requests storage or analysis.

2. NameNode concept:

Tracks file names and logical block metadata.

3. DataNode concepts:

Shows how blocks can be distributed and replicated across nodes.

4. MapReduce:

Mapper emits (word, 1); reducer sums counts for each word.

5. Output:

Displays word frequencies and allows report downloads.

Suggested 3–5 minute presentation

Step 1 — Introduce:

“Large datasets are difficult to store and process on one machine. HDFS distributes file blocks across multiple machines.”

Step 2 — Dashboard:

Explain stored files, total size, blocks and unique words.

Step 3 — Upload:

Click Load sample dataset. Show the input directory in File Management.

Step 4 — Storage:

Open HDFS Storage and explain logical blocks, DataNodes and the illustrative replication factor.

Step 5 — Analysis:

Run MapReduce. Explain Mapper, Shuffle and Sort, and Reducer.

Step 6 — Output:

Show word counts, percentages, chart, then download CSV and report.

Viva questions

What is HDFS?
Hadoop Distributed File System stores large files across a cluster.

What is a NameNode?
It manages filesystem metadata and tracks block locations.

What is a DataNode?
It stores actual HDFS data blocks.

What is replication?
Maintaining multiple copies of blocks for fault tolerance.

What is MapReduce?
A programming model for parallel data processing using map and reduce stages.

What does the mapper do?
It emits each word with a count of one.

What does the reducer do?
It adds counts for each word and outputs the total.
